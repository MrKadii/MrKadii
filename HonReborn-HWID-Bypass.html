What does it do?

Machine identity

Updates MachineGuid, NT Identifier, ComputerName and InstallDate with fresh unique values.

Hardware traces

Refreshes CPU identity/name, BIOS and SMBIOS registry caches, and changes the network adapter MAC address.

Client state

Clears Juvio caches, install.bin and reconnect.cfg identities so the client reads the new identity right away.

Reversible

All previous values are saved to hwid-backup.json on first run; restore them with hwid-restore.bat.

FAQ

Does it work for multiple accounts?

Yes. Each run generates a new identity, so a second account also appears as an independent player.

Did the values come out wrong?

Run hwid-restore.bat — all values backed up on the first run are restored exactly.

Client still shows the old identity?

Close and reopen the client completely. Since caches are cleared, the new identity is read as soon as the window opens.
