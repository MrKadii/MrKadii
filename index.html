What does it do?

Reversible

Why Proxmox: one physical machine hosts many fully isolated environments, each with its own hardware fingerprint — no per-account registry tinkering on the host, and everything is reproducible from the template VM.

FAQ

Does it work for multiple accounts?

Yes. Each run generates a new identity, so a second account also appears as an independent player.

Did the values come out wrong?

Run hwid-restore.bat — all values backed up on the first run are restored exactly.

Client still shows the old identity?

Close and reopen the client completely. Since caches are cleared, the new identity is read as soon as the window opens.
