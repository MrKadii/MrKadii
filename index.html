What does it do?

Machine identity

Client state

Reversible

Full bypass with Proxmox

The most reliable method: run each account inside its own lightweight virtual machine. Every VM exposes completely separate hardware to the client — its own BIOS/SMBIOS tables, CPU string, MachineGuid and MAC address — so each account is seen as a distinct physical machine.

Install Proxmox VE Install Proxmox VE on a spare PC or mini-server (ISO from proxmox.com). Manage everything from the web UI at http://<ip>:8006 — no monitor needed after install.
Create one Windows VM per account Create a Windows 10/11 VM (virtio drivers, ~2 vCPU, 4 GB RAM is enough for HoN). Each VM generates its own unique machine fingerprint on first boot — that alone is already a clean HWID.
Give every VM a distinct MAC In the VM's Network settings set a unique macaddr per VM (e.g. B8:27:EB:00:00:01, ...:02). Without this, cloned VMs could share one adapter identity.
Clone for more accounts Full-clone the template VM for each additional account. Every clone boots with a fresh identity; linked clones share disk but still present separate hardware to the client.
Polish inside the VM Run hwid-spoof.bat inside the VM if you want an extra layer (fresh MachineGuid, cleared client caches). Then launch HoN Reborn and log in — the account is independent.

-cpu host, -hypervisor, kvm=off

Passes the real CPU model through and hides the KVM hypervisor signature, so the client sees bare-metal hardware instead of a virtual machine.

cpu: host + cores: 12

Full host CPU feature set, all cores on one socket — closest match to a physical gaming PC, best in-game FPS.

balloon: 0

Disables memory ballooning so RAM stays fixed at 6 GB; no stutter from dynamic memory changes.

bios: ovmf

UEFI firmware with a real EFI disk — matches how modern physical machines boot.

net0: e1000=…, bridge=vmbr0

Give every VM its own unique MAC address on the bridge — one of the main fingerprints the client reads.

smbios1: uuid=…

A unique SMBIOS UUID per VM completes the identity: MAC + UUID + CPU string = a separate physical machine.

discard=on, ssd=1

Enables TRIM on the ZFS SSD volume so disks stay fast even after many clones.

FAQ

Does it work for multiple accounts?

Yes. Each run generates a new identity, so a second account also appears as an independent player.

Did the values come out wrong?

Run hwid-restore.bat — all values backed up on the first run are restored exactly.

Client still shows the old identity?

Close and reopen the client completely. Since caches are cleared, the new identity is read as soon as the window opens.
